# TP Final — Automatización

## Sistema inteligente de triage de tickets de soporte

Proyecto final desarrollado con n8n, Airtable, Gmail, DeepSeek, Slack y HITL para clasificación, trazabilidad, control de errores y monitoreo operativo.

## Estructura del repositorio

- `01_Arquitectura` — Diagrama de arquitectura
- `02_Datos` — Manual operativo de datos
- `03_Costos` — Matriz comparativa de costos
- `04_Seguridad` — Seguridad y resiliencia
- `05_Dashboard` — Dashboard de control
- `06_Testing` — Evidence Pack y pruebas
- `07_Workflow` — Workflow final en JSON
- `08_Evidencias` — Capturas principales
- `09_Aclaraciones` — Aclaraciones técnicas y de evaluación

## Componentes principales

- Gmail Trigger
- Filtro NO.REPLY
- Anti-duplicación por Gmail Message ID
- Validación de datos mínimos
- Airtable
- AI Agent
- DeepSeek Flash
- Structured Output Parser
- Memoria Contextual por Gmail Thread ID
- Priorización Baja / Media / Alta / Crítica
- HITL
- Error Handling
- Slack
- Dashboard de monitoreo
